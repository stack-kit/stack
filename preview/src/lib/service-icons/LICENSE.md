# The licence of the service icons

The icons beside this file draw the marks of seven outside services. Each `<path>` is a copy, as text, of the path of the mark in Simple Icons 16.38.0 (`https://github.com/simple-icons/simple-icons`, the npm package `simple-icons`). STACK added only the frame of a component and a transform that draws the path inside 22 of the 24 units.

| File | Service | Icon in Simple Icons 16.38.0 |
|---|---|---|
| `WhatsApp.svelte` | WhatsApp | `icons/whatsapp.svg` |
| `Viber.svelte` | Viber | `icons/viber.svg` |
| `Telegram.svelte` | Telegram | `icons/telegram.svg` |
| `Messenger.svelte` | Messenger | `icons/messenger.svg` |
| `Instagram.svelte` | Instagram | `icons/instagram.svg` |
| `Signal.svelte` | Signal | `icons/signal.svg` |
| `Gmail.svelte` | Gmail | `icons/gmail.svg` |

Simple Icons publishes the project under CC0-1.0 (`https://creativecommons.org/publicdomain/zero/1.0/`), and its data for 16.38.0 gives none of these seven icons a licence of its own. CC0 asks for no notice. This file names the source and its version, so that the next update starts from them.

Each mark is a trademark of its owner. CC0 covers the drawing of the path only, and neither Simple Icons nor STACK grants a licence to a mark. A product that shows a mark uses it under the terms of its owner, such as the brand guidelines of the service.
